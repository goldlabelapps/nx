Python° is a RESTful API built with **FastAPI**, providing high performance and easy-to-use endpoints. The python app is deployed to [Render.com](https://render.com/), ensuring reliable and scalable hosting. 

For data storage, **Postgres** is Python°'s primary database. This combination ensures a robust, production-ready, and open-source solution optimized for speed and reliability

A crucial and distinctive feature of our stack is the use of the **tsvector** data type in Postgres. By utilizing tsvector for full-text search, our application achieves superfast and efficient search capabilities, even with large datasets. 
This enables users to experience near-instantaneous search results, 
making our platform highly responsive and scalable.
