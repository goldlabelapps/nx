## Prerequisites

* **Node.js:** 20 LTS or newer
* **Package Manager:** pnpm (recommended)

## Clone the Repository

```bash
git clone https://github.com/goldlabelapps/nx.git
cd nx
```

## Install Dependencies

```bash
pnpm install
```

## Run and Use the CLI

Launch the interactive NX° CLI from the repository root:

```bash
node ./packages/cli/bin/cli.js
```
