# GpxRoute° Documentation Hub

Welcome to the **GpxRoute°** documentation directory. This project is built from scratch exclusively using **Google Antigravity** as an AI pair programming environment.

Beyond standard technical specifications, this repository treats **the AI-assisted development process as a primary project artifact**, documenting the decisions, iteration loops, and engineering patterns that emerge when building software with an intelligent agent.

## Guiding Principles

1. **Clean Slate, Intentional Stack**: Every layer of the stack (framework, styling, state, map rendering, deployment) is added deliberately with zero deadweight.
2. **AI-First Documentation**: Every major architectural pivot, design choice, and debugging session is captured in the documentation.
3. **Show, Don't Just Tell**: GPX data should be dynamic, visually stunning, and instantly shareable, moving beyond static GPS charts into immersive 3D route experiences.
