## Quick Start (Install & Use)

Follow this simple flow to get up and running:

1. **Clone the repository and enter directory**:
   ```bash
   git clone https://github.com/goldlabelapps/nx.git
   cd nx
   ```

2. **Add environment credentials**:
   ```bash
   cp apps/nx/.env.example apps/nx/.env.local
   # Update apps/nx/.env.local with any required credentials/keys
   ```

3. **Install dependencies**:
   ```bash
   pnpm install
   ```

4. **Run the CLI & execute tests**:
   ```bash
   pnpm cli
   ```

5. **Start the development server**:
   ```bash
   pnpm dev
   ```

6. **Verify hot reloading**:
   Open the codebase in your code editor. Edit the hero text component in `apps/nx/src/app/page.tsx` (or `apps/nx/src/components/Hero.tsx`) to verify live updates in your browser.
