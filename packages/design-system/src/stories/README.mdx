# Design System Storybook

This workspace is the visual and behavioral reference for the shared NX design-system package.

## How To Use This Workbench

- Use **Brand** for identity primitives and color references.
- Use **Headings** for small-label typography patterns.
- Use **Feedback** for form and messaging UI.
- Use **Layout** for page shell and site chrome pieces.
- Use **Navigation** for hierarchical menus.
- Use **Responsive** for viewport-aware helpers.
